# TimewarpTCG

Juego de cartas por turnos con carriles. Backend Java (Spring Boot) + cliente Unity.

| Carpeta | Qué es |
|---|---|
| `TimewarpTCG.Back/` | Backend (Java 21+, Spring Boot, Supabase/PostgreSQL). Arranque rápido: `arrancar-backend.cmd` (Windows) |
| `TimewarpTCG.Unity/` | Cliente Unity (los scripts están en `Assets/Timewarp`) |
| `docs/` | **Empieza por `GUIA_ARRANQUE.md`**. También: reglas del juego, problemas conocidos, seguridad, catálogo de cartas y SQL de Supabase |
| `tools/` | Pruebas sin Unity y generador de SQL del catálogo |
